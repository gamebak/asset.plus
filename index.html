Approach

Zero dependencies is the aspiration, not the constraint. Every line has to earn its place.

Origin

It all started on a Commodore 64.

In my early years I spent my time on a Commodore 64, where even loading a program from a floppy disk was troublesome: type LOAD"*",8,1, wait, and hope it didn't end in ?LOAD ERROR. Seeing how far things have come since then never gets old.

Memory
64 KB→16 GB+ (~260,000×)
CPU
~1 MHz, 8-bit→GHz, many cores
Storage
170 KB floppy→TBs + the cloud
Loading
minutes, if it worked→instant

The hardware got hundreds of thousands of times more powerful. That's exactly why today's software has no excuse to be slow.
